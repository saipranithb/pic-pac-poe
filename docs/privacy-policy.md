# Pic-Pac-Poe privacy policy

Effective: 2026-09-01

Pic-Pac-Poe is an offline game. It does not collect, transmit, sell, or share personal data.

- The app requests no Internet permission.
- There are no analytics, advertising, account, Firebase, networking, or cloud-AI SDKs.
- Matches and AI computations run locally on the device.
- Sound, haptics, theme, and reduced-motion preferences are stored locally with Android DataStore while the app remains installed.
- Android may retain the current local game and screen state so an interrupted activity can be restored. This state is not sent to the developer or any third party.
- Android cloud backup and device-to-device transfer are disabled for the application. The manifest disables backup, and the extraction rules exclude every eligible app-data storage domain.

The app has no account and therefore holds no account data to delete. A user can delete all locally stored app data at any time from Android's app-storage settings, or by uninstalling Pic-Pac-Poe. No server-side deletion request is necessary because the app has no server and the developer receives no app data.

The open-source project and issue tracker may be hosted by a third-party code platform. Activity on that platform is governed by the platform's own privacy terms and is separate from the Android app.

Questions about this policy can be raised through the project's public issue tracker: https://github.com/saipranithb/PicPacPoe/issues. Do not include personal or sensitive information in a public issue.
